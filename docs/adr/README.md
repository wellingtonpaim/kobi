# ADRs — registros de decisões arquiteturais

Cada decisão arquitetural nova ganha um arquivo `NNNN-titulo-curto.md`:

```
# NNNN — Título

- Status: proposta | aceita | substituída por NNNN
- Data: AAAA-MM-DD

## Contexto
O problema e as forças envolvidas.

## Decisão
O que foi decidido.

## Consequências
Ganhos, custos e o que muda daqui pra frente.
```

As decisões tomadas no planejamento inicial estão consolidadas em `docs/decisoes.md`.
