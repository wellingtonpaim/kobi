# Specs

Cada funcionalidade ganha uma spec **antes do código** (Spec-Driven Development). Arquivo `NNNN-titulo-curto.md`:

```
# NNNN — Título

- Fase: N
- Status: rascunho | aprovada | implementada

## Objetivo
O que o usuário ganha e por quê.

## Comportamento
Regras e cenários, de preferência no formato "dado / quando / então".

## Fora do escopo
O que fica para depois.

## Critérios de aceite
Lista verificável; vira testes.

## Desempenho
Metas de docs/performance.md que se aplicam, e como medir.
```
